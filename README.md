# Retail Sales Forecasting & Inventory Optimization Using Machine Learning

An end-to-end Machine Learning project focused on retail demand forecasting and inventory optimization using Python.

## Project Overview

Accurate sales forecasting helps retail businesses understand future product demand, improve inventory planning, and reduce stock-related challenges.

This project develops a machine learning-based forecasting system that analyzes historical retail sales data and predicts future demand. It also applies inventory optimization techniques to support better replenishment decisions.

## Objectives

- Analyze historical retail sales patterns.
- Perform data preprocessing and exploratory data analysis.
- Engineer features for demand forecasting.
- Build and evaluate machine learning models.
- Forecast retail demand for the next 30 days.
- Calculate safety stock and reorder points.
- Support data-driven inventory planning.

## Dataset

The project uses a generated retail sales dataset containing:

- 43,840 sales records
- 5 retail stores
- 8 products

The dataset is generated within the notebook, so a separate dataset download is not required.

## Machine Learning Models

The project explores:

1. Random Forest
2. Gradient Boosting

Time-based feature engineering is used to prepare the data for demand forecasting.
